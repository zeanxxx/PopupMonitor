# PopUp Monitor

A lightweight Windows system tray utility that automatically detects and hides pop-up windows from Windows Live Captions.

### Features

* Runs quietly in the system tray.
* Start or stop monitoring at any time.
* Automatically detects and hides Live Captions pop-up windows.

### Usage

Run the application and enable monitoring from the system tray.

**Note:** Disable monitoring before interacting with Live Captions.

## 中文说明

PopUp Monitor 是一款轻量级 Windows 系统托盘工具，可自动检测并隐藏 Windows 实时字幕（Live Captions）的弹出窗口。

### 主要功能

* 在系统托盘中运行。
* 随时开启或停止监测。
* 自动检测并隐藏实时字幕弹窗。

### 使用说明

启动程序后，可通过系统托盘菜单开启或停止监测。

**注意：** 如需操作实时字幕，请先停止监测。
