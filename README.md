# PopUp Monitor

A lightweight Windows 11 system tray utility that automatically detects and hides unwanted pop-up windows from Windows Live Captions.

### Background

Windows 11's built-in Live Captions feature may repeatedly display pop-up windows, interrupting the user experience.

PopUp Monitor was created to address this issue by automatically detecting and hiding these pop-ups, allowing users to enjoy Live Captions with fewer interruptions.

### Features

* Runs quietly in the system tray.
* Start or stop monitoring at any time.
* Automatically detects and hides Live Captions pop-up windows.

### System Requirements

* Windows 11

### Usage

Run the application and enable monitoring from the system tray.

**Note:** Disable monitoring before interacting with Live Captions.

## 弹窗监控工具

PopUp Monitor 是一款适用于 Windows 11 的轻量级系统托盘工具，可自动检测并隐藏 Windows 实时字幕（Live Captions）的弹出窗口。

### 开发背景

Windows 11 自带的实时字幕功能在使用过程中可能反复出现弹窗，影响正常使用体验。

为了解决这个问题，开发了 PopUp Monitor，通过自动检测并隐藏实时字幕弹窗，减少弹窗对日常使用的干扰。

### 主要功能

* 在系统托盘中运行。
* 随时开启或停止监测。
* 自动检测并隐藏实时字幕弹窗。

### 运行环境

* Windows 11

### 使用说明

启动程序后，可通过系统托盘菜单开启或停止监测。

**注意：** 如需操作实时字幕，请先停止监测。
